# simple-calculator

A clean and functional calculator built with HTML, CSS, and embedded JavaScript.

## Features
* Basic operations: Addition, Subtraction, Multiplication, Division.
* Responsive design for mobile and desktop.
* "Clear" button to reset calculations.

## Built With
* **HTML5** - For the structure.
* **CSS3** - For the styling and layout.
* **JavaScript** - For the calculation logic.

## How to Use
1. Clone the repository.
2. Open `index.html` in your browser.
3. Start calculating!

##  How it Works
The JavaScript file uses **Event Listeners** to detect when a button is clicked. It then updates the display and uses logic to calculate the final result.
